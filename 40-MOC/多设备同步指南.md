# 多设备同步 / 新电脑下载笔记指南

你的笔记已通过 Obsidian Git 实时备份到 GitHub 私有仓库 `nerfwth/note`。
在另一台电脑上"下载笔记" = **`git clone` 这个仓库**。本文说明完整步骤与注意事项。

---

## 方式一：Git Clone（推荐，完整 + 自动备份）

### 1. 前置准备（新电脑一次性）
- **安装 Obsidian**：https://obsidian.md/download （按系统装，打开过一次即可）
- **安装 Git**：https://git-scm.com/downloads （Windows 装 Git for Windows；Mac 用 `brew install git`；Linux 用包管理器）
- **配置 GitHub 访问（二选一）**
  - **SSH（推荐）**：
    ```bash
    # 生成密钥（一路回车）
    ssh-keygen -t ed25519 -C "你的邮箱"
    # 复制公钥内容（Windows 用下面命令，Mac/Linux 用 cat）
    cat ~/.ssh/id_ed25519.pub
    ```
    把输出的整段公钥，粘贴到 GitHub 网页 → 右上角头像 → **Settings → Access → SSH and GPG keys → New SSH key**（Title 写"新电脑"）。
  - **HTTPS + 凭据管理器**：无需配 key，首次 push 时浏览器登录 GitHub 账号即可（Git Credential Manager 会自动保存）。

### 2. 下载笔记
打开终端 / PowerShell / Git Bash，执行：
```bash
git clone git@github.com:nerfwth/note.git "E:/note"
```
> 把末尾路径换成你想放的位置，例如 macOS/Linux 可写 `~/note`，Windows 也可写 `D:/note`。
> 若用 HTTPS，把地址换成 `https://github.com/nerfwth/note.git`。

### 3. 用 Obsidian 打开
Obsidian 启动页 → **打开本地仓库 / Open folder as vault** → 选刚才 clone 下来的文件夹。
首次打开会提示"是否信任此仓库的插件" → 选 **信任**（因为插件是随仓库一起下来的，已是你自己装的）。

### 4. 补上远程地址（关键！）
`.git/config` 不会被 git 跟踪，所以 clone 下来**没有 origin 远程**，Obsidian Git 无法自动推送。
在终端进入该文件夹执行：
```bash
git remote add origin git@github.com:nerfwth/note.git
# 若用 HTTPS：git remote add origin https://github.com/nerfwth/note.git
```
然后重载 Obsidian（`Ctrl/Cmd + P` → 输入 `Reload app without saving`）。
之后 Obsidian Git 会按原配置（每 10 分钟）自动 commit + push，多设备闭环就通了。

## 同步了什么 / 没同步什么

| 会同步（clone 即到位） | 不会同步（需手动处理） |
|---|---|
| 全部 `.md` 笔记、模板、MOC | **PDF 文献**（被 `.gitignore` 排除，防仓库膨胀） |
| 所有插件文件与启用配置（dataview / obsidian-git / pdf-plus / templater / zotero 连接器 / minimal-settings 等） | 窗口布局 `workspace.json`（多设备会冲突，已排除，新电脑会自动重建） |
| 主题（Minimal / AnuPpuccin）与外观设置 | — |
| Obsidian Git 的自动备份配置（间隔参数已随 `data.json` 同步） | `origin` 远程地址（需按上面第 4 步手动加） |

**结论**：clone + 加 remote 后，笔记、插件、主题、外观、自动备份**全自动恢复**；唯一要补的是把 PDF 文献文件手动复制到新电脑对应位置（或用 Zotero 重新同步 PDF）。

## 方式二：GitHub 网页下载 ZIP（临时查看，不推荐长期使用）
GitHub 网页 `nerfwth/note` → **Code → Download ZIP**。
解压后用 Obsidian 打开即可看笔记。
缺点：没有 `.git` 历史、Obsidian Git 不会自动备份（因为没有 git 仓库），仅适合临时查阅。

## 常见问题
- **Q：新电脑 clone 后插件没生效？**
  A：确认打开 vault 时选了"信任插件"；然后 `Ctrl/Cmd + P` → `Reload app without saving` 重载一次。
- **Q：状态栏报 "remote origin already exists" 或 "remote not found"？**
  A：用 `git remote -v` 查看；若地址不对，`git remote set-url origin <正确地址>` 修正。
- **Q：两台电脑同时改同一篇笔记会冲突吗？**
  A：Obsidian Git 自动推送间隔内各自 commit，理论上可能冲突。建议改完等几秒让自动 push 完成，再在另一台 `Ctrl/Cmd + P` → `Git: Pull` 拉取。真冲突时插件会提示，按提示合并即可。
- **Q：PDF 怎么跟着走？**
  A：`.gitignore` 刻意不跟踪 PDF。最干净的做法是用 Zotero 管理 PDF，Obsidian 只存笔记与链接；或手动把 PDF 文件夹拷到新电脑相同相对路径。
