# 插件配置指引（Dataview + PDF++）

> 这两个插件已安装并启用。下面是如何用起来的关键设置，都在 Obsidian「设置 → 第三方插件」里对应插件下。

## 一、Dataview（知识库自动聚合）
- 作用：让 `40-MOC/文献管理 MOC.md` 里的查询渲染成表格/列表。
- 装好即用，无需复杂设置。
- 想写自己的查询：在任意笔记用 ` ```dataview ` 代码块，语法见 [Dataview 文档](https://blacksmithgu.github.io/obsidian-dataview/)。
- MOC 已内置四个视图：未读文献、已读文献、最新卡片、按主题。

## 二、PDF++（PDF 标注 ↔ 笔记双向链接）
PDF++ 让 PDF 里的高亮/批注能直接变成可链接的笔记。

**关键设置（设置 → PDF++）：**
1. 开启「Annotations」相关选项，允许在 PDF 中直接写 Markdown 评论（支持 `[[双向链接]]`）。
2. 开启「自动生成标注的 Markdown 评论」——高亮即出现可编辑评论框。
3. 批量导出：命令面板（`Ctrl+P`）搜 `PDF++: Extract annotations into Markdown file`。

**标注提取工作流：**
1. 在 Obsidian 打开一篇 PDF（直接点文件，或 `PDF++: Open in new tab`）。
2. 用 PDF++ 高亮工具选中文字 → 自动出现评论框 → 写批注，可插入 `[[概念]]` 链接到其它笔记。
3. 想汇总：命令面板 `Extract annotations into Markdown file`，生成带链接的标注笔记，放进 `20-Notes/` 或 `10-Literature/` 对应文献下。
4. 这些链接会进入图谱和 MOC 查询，知识网就织起来了。

**注意：**
- PDF 文件已被 `.gitignore` 排除（`*.pdf`），不会进 git 仓库，仓库保持轻量；PDF 本地读即可。
- 若某设置项名称与你版本不符，以 Obsidian 内实际显示为准（PDF++ 更新快，开关位置可能微调）。

- 卡片用 `90-Templates/zettel.md`。
