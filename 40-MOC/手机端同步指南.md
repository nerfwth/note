# 安卓手机同步 Obsidian 笔记指南

你的笔记已通过 Obsidian Git 实时备份到 GitHub 私有仓库 `nerfwth/note`。
在安卓手机上同步 = **让手机 Obsidian 也连同一个 GitHub 仓库**，和桌面 `E:\note` 互通。

---

## ⚠️ 必须先知道的三件事

1. **手机端 Obsidian Git 插件不支持 SSH。**
   桌面端用的是 `git@github.com:nerfwth/note.git`（SSH），但手机插件底层是 JS 重写的 `isomorphic-git`，**只支持 HTTPS + 个人访问令牌(PAT)**。所以手机端要改用 `https://github.com/nerfwth/note.git` + PAT 登录（和桌面 SSH 互不冲突，指向同一仓库）。
2. **插件移动端"能用但不稳"。**
   官方明确不推荐在手机上用 Obsidian Git，大仓库首次 clone 可能闪退。你的仓库是纯文本（笔记/插件/主题），体积可控，**大概率能跑通**；若闪退，见下方「方案 B」。
3. **PDF 不进 git。**
   和桌面一致，手机端看不到 PDF 文献（`.gitignore` 刻意排除），需手动复制或用 Zotero 同步。

---

## 方案 A：Obsidian Git 插件 + HTTPS PAT（推荐先试，最简单）

### 1. 生成 GitHub 个人访问令牌（PAT）
1. 电脑/手机浏览器打开 GitHub → 右上角头像 → **Settings**
2. 滚动到最底部 → **Developer settings** → **Personal access tokens** → **Tokens (classic)** → **Generate new token**
3. Note 填 `obsidian-android`；Expiration 按需选（如 90 天）
4. 勾选 **`repo`**（完整控制私有仓库）这一项即可
5. 点 **Generate token** → **复制那串 token（只显示一次，保存到备忘录）**

### 2. 手机装 Obsidian
应用商店搜 Obsidian 安装，或到 obsidian.md 下载官方 APK。

### 3. 手机装 Obsidian Git 插件
Obsidian → 设置 → 第三方插件（Community plugins）→ 关掉安全模式 → 浏览 → 搜 **Obsidian Git** → 安装并启用。

### 4. 首次 clone 仓库
- 在 Obsidian 里「创建新仓库 / Create new vault」时，选择 **Clone an existing remote repository**（或在插件设置里找 clone 选项）。
- 远程 URL 填：`https://github.com/nerfwth/note.git`
- 用户名：`nerfwth`
- 密码 / Token：粘贴**第 1 步的 PAT**（不是你的 GitHub 登录密码）
- 等待 clone 完成（纯文本仓库一般很快）。

### 5. 日常同步
- 建议开启：**设置 → Obsidian Git → 勾选 "Auto pull on startup"**（打开时自动拉取最新）。
- 手动推送：命令面板（`⋮` → 命令）→ `Git: Commit and sync`，或点状态栏的 Git 图标。
- **移动端不要开「每 N 分钟自动 sync」**，易和桌面端冲突；养成「改完手动 sync」的习惯。

### 6. 验证
手机新建一条测试笔记 → `Commit and sync` → 去 GitHub 网页 `nerfwth/note` 看是否出现；再回桌面 Obsidian 手动 pull，确认互通。

## 方案 B：Termux 跑原生 git（最稳，适合方案 A 闪退时）

思路：用 Termux 提供**原生 git**（支持 SSH、稳定），Obsidian 只负责写笔记。

1. **装 Termux**：务必从 **F-Droid** 或 GitHub 下载（别用 Play 商店版，已停更）。
2. Termux 里执行：
   ```bash
   termux-setup-storage        # 授权存储
   pkg update && pkg install -y git openssh
   ssh-keygen -t ed25519 -C "android"   # 一路回车
   cat ~/.ssh/id_ed25519.pub   # 复制，加到 GitHub SSH keys（和桌面同一个账号）
   cd ~/storage/shared
   git clone git@github.com:nerfwth/note.git   # 用你熟悉的 SSH，原生 git 稳定
   ```
3. 手机 Obsidian 打开 `~/storage/shared/note` 文件夹，信任插件即可。
4. （可选进阶）用 Tasker 实现「打开 Obsidian 时 pull、关闭时 push」自动化——搜索 `obsidian-android-sync` 项目有现成配置。

---

## 冲突与注意事项
- **同一篇笔记别两台设备同时改**：先在一台 `sync`，再到另一台 `pull` 后再改。
- **不要把这个 vault 同时丢进 Syncthing / 网盘同步**：会和 git 仓库状态打架，导致损坏。要么用 git（本方案），要么用网盘（二选一）。
- **手机端别开后台自动 sync**：手动 `Commit and sync` 最安全。

## 桌面 vs 手机的协议对照
| 设备 | 地址 | 认证 |
|---|---|---|
| 桌面 `E:\note` | `git@github.com:nerfwth/note.git` | SSH key（已配） |
| 安卓手机 | `https://github.com/nerfwth/note.git` | HTTPS + PAT（本指南配置） |

两者指向**同一个仓库**，互不干扰，都能 push/pull，笔记实时互通。
