# 安卓手机同步 Obsidian 笔记指南

你的笔记已通过 Obsidian Git 实时备份到 GitHub 私有仓库 `nerfwth/note`。
在安卓手机上同步 = **让手机也连同一个 GitHub 仓库**，和桌面 `E:\note` 互通。

> ✅ 当前选定方案：**方案 B（Termux 原生 git）**——最稳，支持 SSH，和你桌面端完全一致。

---

## ⚠️ 必须先知道的两件事

1. **手机端 Obsidian Git 插件不稳定**：它底层是 JS 重写的 `isomorphic-git`，不支持 SSH、官方不推荐手机端使用、大仓库易闪退。所以本方案**不走插件**，改用 Termux 跑原生 git（和桌面一模一样）。
2. **PDF 不进 git**：和桌面一致，手机端看不到 PDF 文献（`.gitignore` 刻意排除），需手动复制或用 Zotero 同步。

---

## 方案 B：Termux 原生 git（已选用，最稳）✅

### 核心思路
用 **Termux** 提供原生 git（支持 SSH），**Obsidian 只负责写笔记**。
**关键：手机 Obsidian 里不要装 / 不要启用 Obsidian Git 插件**——否则 Termux 和插件会双重管理同一个 git 仓库、互相打架。git 全交给 Termux。

### 步骤 1：装 Termux（关键：别用 Play 商店版）
Termux 在 Google Play 的版本已停更、会报错。从以下任一安装：
- **F-Droid**：https://f-droid.org/packages/com.termux/
- **GitHub Releases**（下 `universal` APK）：https://github.com/termux/termux-app/releases

装好后打开，允许存储权限。

### 步骤 2：Termux 基础环境
```bash
termux-setup-storage          # 弹窗授权允许；之后 ~/storage/shared 指向手机内部存储
pkg update
pkg upgrade -y                # 升级时若询问：openssl.cnf 选 N，sources.list 选 Y，bash.bashrc 选 N
pkg install -y git openssh
```
> 国内网络慢，可先换源：`termux-change-repo` → 选国内镜像（如清华大学/中科大）。

### 步骤 3：生成 SSH key 并加到 GitHub
```bash
ssh-keygen -t ed25519 -C "android"     # 一路回车，不设密码最省事
cat ~/.ssh/id_ed25519.pub               # 复制输出的整段公钥
```
- 到 GitHub 网页 → 头像 → **Settings → Access → SSH and GPG keys** → **New SSH key**
- Title 写 `android-phone`，粘贴公钥 → **Add SSH key**
- 测试连通：
  ```bash
  ssh -T git@github.com        # 输入 yes 信任，看到 "Hi nerfwth!" 即成功
  ```
  > 若提示 `Connection closed by port 22`（被网络限制），改用 443：
  > `ssh -T -p 443 git@github.com`
  > 或长期在 `~/.ssh/config` 加一段走 443 的配置。

### 步骤 4：clone 仓库
```bash
cd ~/storage/shared
git clone git@github.com:nerfwth/note.git
```
完成后笔记在 `~/storage/shared/note`（即手机内部存储的 `note` 文件夹）。

### 步骤 5：手机 Obsidian 打开
- 打开 Obsidian → **打开本地仓库 / Open folder as vault** → 选 **内部存储 → note** 文件夹
- 首次打开提示"是否信任此仓库的插件" → 选 **信任**（插件是随仓库一起来的，都是你自己的）
- **不要装 Obsidian Git 插件**（git 交给 Termux 管）

### 步骤 6：日常同步（在 Termux 里手动执行）
想同步时打开 Termux：
```bash
cd ~/storage/shared/note
git pull                                   # 先拉取桌面端最新改动
# 切到 Obsidian 写笔记……
git add -A
git commit -m "android update"
git push
```
嫌麻烦可设一键别名（写入 `~/.bashrc`）：
```bash
echo "alias gsync='git add -A && git commit -m \"android update\" && git pull --rebase && git push'" >> ~/.bashrc
source ~/.bashrc
# 之后进目录直接敲 gsync 即可完成「提交+拉取+推送」
```

### 步骤 7（可选）：Tasker 自动化开/关自动同步
进阶玩法：用 Tasker 做到「打开 Obsidian 自动 pull、关闭时自动 push」。
可参考 `obsidian-android-sync`（GitHub 搜 `DovieW/obsidian-android-sync`）项目的现成 Tasker 配置。
初级用户可先跳过，手动 `gsync` 已足够好用。

### 方案 B 注意事项
- **Termux 锁屏可能被系统杀进程**：clone/pull 大操作时保持屏幕常亮，并在系统设置把 Termux 省电策略设为"无限制"。
- **冲突避免**：同一篇笔记别桌面与手机同时改；push 前先 `git pull`。
- 你的仓库纯文本、体积小，原生 git 处理毫无压力，比插件稳得多。

## （备选）方案 A：Obsidian Git 插件 + HTTPS PAT
若你日后想试更"无命令行"的方式，可用此方案（但移动端不稳，仅供参考）：

1. GitHub 生成 PAT：Settings → Developer settings → Personal access tokens → Tokens (classic) → 勾选 `repo` → 复制 token。
2. 手机 Obsidian 装 Obsidian Git 插件。
3. 新建 vault 选 **Clone an existing remote repo**，URL 填 `https://github.com/nerfwth/note.git`，用户名 `nerfwth`，密码填 **PAT**。
4. 开启 Auto pull on startup，改完手动 `Git: Commit and sync`。

> 注意方案 A 用 **HTTPS+PAT**，与方案 B 的 **SSH** 指向同一仓库、互不冲突，但不能两套同时启用。

## 桌面 vs 手机协议对照
| 设备 | 地址 | 认证 |
|---|---|---|
| 桌面 `E:\note` | `git@github.com:nerfwth/note.git` | SSH key（已配） |
| 安卓手机（方案 B） | `git@github.com:nerfwth/note.git` | SSH key（Termux 生成，本指南配置） |

两者都指向**同一个仓库**，都用 SSH，互不干扰，都能 push/pull，笔记实时互通。

## 通用冲突与注意事项
- **同一篇笔记别两台设备同时改**：先在一台 sync，再到另一台 pull 后再改。
- **不要把这个 vault 同时丢进 Syncthing / 网盘同步**：会和 git 仓库状态打架，导致损坏。要么用 git（本方案），要么用网盘（二选一）。
