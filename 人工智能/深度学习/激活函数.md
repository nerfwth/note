# 每个神经元
- 线性组合
- 非线性映射，使神经网络得以拟合任意复杂的函数
# 为什么WX+b（线性）：
- 线性的工程红利
	- 可以用矩阵乘法表示，利于硬件加速
	- 梯度极简
- 数值会指数级膨胀
	- 前向：幂次极大
	- 反向：求导系数巨大
# 工程解法
线性变换+独立非线性激活
激活函数挑选输出有界或导数温和的形式，主动掐断指数膨胀的传染链。
# 激活函数的要求
- 非线性
- 几乎处处可导
- 梯度良好，最好接近1
- 计算便宜
- 输出零中心，避免梯度方向被锁死，优化更顺
- 单调、有界、平滑
