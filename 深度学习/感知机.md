# 单层感知机
- 由一个输入层和一个输出层构成，输出层输出 -1 或 1
- 可作为一种二类线性分类模型
- 单层感知机构建损失函数来计算模型预测值与数据真实值之间的误差，通过修改权重最小化损失函数值，来优化模型参数
- 单层感知机只能用来解决线性可分问题，解决不了XOR（异或问题）
# 多层感知机
 **MLP（Multilayer Perceptron，多层感知机）是一种人工[[前馈神经网络]]，由输入层、一个或多个隐藏层和输出层组成，常用于分类、回归等监督学习任务。** 它通过全连接层和非线性激活函数（如 ReLU、tanh、sigmoid）实现对复杂非线性关系的建模 。
## 引入原因
- 用两层感知机解决XOR问题
## 多层结构的两个思想来源
- 神经科学：大脑皮层分层处理
- 函数逼近理论
## 结构
- **输入层**：接收特征向量。
- **隐藏层**：一个或多个，每层由若干神经元组成，使用激活函数引入非线性。
- **输出层**：根据任务使用 softmax（分类）或线性输出（回归）。
- 输入层接受原始特征，数个隐藏层进行中间运算，输出层给出最终结果
- 同一层里的神经元并行提取多个不同的特征或规则
- 后续层将前一层的输出作为输入，利用不同的权重进一步组合逐层构造出更抽象、更有用的表示
- 如何训练模型是个问题->[[反向传播算法（Backpropagation）]]
## 工作原理
- 前向传播
- 反向传播
	- 梯度下降（SGD）
	- Adam
	- Momentum
