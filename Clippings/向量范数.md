向量范数 是数学中用于衡量向量大小或长度的一类函数，其定义必须满足正定性、绝对齐次性和三角不等式三个核心性质。常见的范数包括 L1、L2 和无穷范数，它们在工程、物流及数据科学领域中被广泛用于定义不同的几何空间和距离度量。向量范数在模型正则化、算法优化以及设定安全容差等实际应用中发挥着至关重要的作用。

关键要点

- 向量范数是衡量向量“长度”的函数，必须遵循正定性、绝对齐次性和三角不等式三大公理。
- L1（曼哈顿）、L2（欧几里得）和L∞（最大值）范数是三种核心的度量方式，分别代表了沿轴线移动的总距离、空间直线距离和最大分量。
- 范数的选择决定了问题的解决方案：L2范数是最小二乘法的基础，L1范数在机器学习中诱导稀疏解，而L∞范数则用于评估工程安全中的最坏情况误差。


## 引言

在数学、工程和数据科学的世界中，我们经常需要量化一个对象的“大小”或“重要性”。对于简单的数字，我们可以用 [绝对值](https://www.bohrium.com/sciencepedia/feynman/keyword/absolute_value) 来衡量。但当我们面对的是一个由多个数值组成的向量——例如，空间中的一个点、一组实验数据或机器学习模型的权重——我们该如何衡量它的“大小”呢？正是为解决这一基本问题而生的强大数学工具，它为我们提供了一把在多维空间中测量“长度”或“距离”的抽象标尺。

然而，这把标尺并非只有一种。我们对“长度”的直观理解在抽象空间中会遇到挑战，催生了多种不同的度量方式。选择哪一种“标尺”，将深刻影响我们如何分析误差、构建模型以及从数据中提取洞见。本文旨在系统地介绍的概念，并揭示其在不同领域的广泛应用。

在接下来的内容中，我们将分三步深入探索的世界。首先，在 **“原则与机制”** 一章中，我们将学习定义范数的数学公理，并认识最核心的范数家族（L1、L2、 [无穷范数](https://www.bohrium.com/sciencepedia/feynman/keyword/infinity_norm_2) ），理解它们各自的几何意义。接着，在 **“应用与 [交叉](https://www.bohrium.com/sciencepedia/feynman/keyword/decussation) 学科联系”** 一章中，我们将看到这些抽象概念如何在工程、数据科学和经济学等领域解决实际问题，从 [最小二乘法](https://www.bohrium.com/sciencepedia/feynman/keyword/method_of_least_squares) 到现代机器学习的稀疏革命。最后，在 **“动手实践”** 部分，你将通过解决具体问题，亲手运用这些知识，巩固并深化你的理解。让我们一同开启这段旅程，去发现这些优雅的数学工具是如何塑造我们对世界的量化认知的。

## 何为向量范数？

想象一下，你手上有一把尺子。你希望它具备哪些基本功能？
1. 首先，只有当起点和终点重合时，测量出的长度才应该是零。
2. 其次，如果你测量的距离扩大一倍，尺子上的读数也应该相应地扩大一倍。
3. 最后，从A点到B点再到C点的距离，总不会比直接从A点到C点的距离更短——我们都知道，两点之间直线最短。

 ### 向量范数的公理化定义

1. **[正定性](https://www.bohrium.com/sciencepedia/feynman/keyword/positive_definiteness_2) (Positive Definiteness)** 
    一个 [向量的范数](https://www.bohrium.com/sciencepedia/feynman/keyword/norm_of_a_vector) 必须是正数，并且只有 **[零向量](https://www.bohrium.com/sciencepedia/feynman/keyword/zero_vector)** （即所有分量都为零的向量）的范数才为零。这保证了每个非零向量都有其独特的“大小”。
2. **绝对齐次性 (Absolute Homogeneity)**
	 将一个向量 $\vec{v}$ 乘以一个标量 $c$ （即将其所有分量都乘以 $c$ ），其新的范数等于原范数的 $|c|$ 倍，即 $\|c\vec{v}\| = |c|\|\vec{v}\|$ 。这意味着，如果你将向量的方向反转（ $c=-1$ ），其长度不变；如果你将其长度加倍（ $c=2$ ），其范数值也加倍。
3. **[三角不等式](https://www.bohrium.com/sciencepedia/feynman/keyword/triangle_inequality) (Triangle Inequality)**
	两个向量之和的范数，小于或等于这两个的和，即 $\|\vec{u} + \vec{v}\| \le \|\vec{u}\| + \|\vec{v}\|$ 。这正是“两点之间直线最短”这一几何直觉在任意维度空间中的抽象表达。

任何一个函数，只要它能对一个 [向量空间](https://www.bohrium.com/sciencepedia/feynman/keyword/vector_spaces) 里的所有向量赋予一个“长度”值，并且始终遵守这三条法则，我们就可以称之为一个合法的范数。


 ### $Lp$ 范数

#### $L2$范数：我们最熟悉的朋友

$L_2$ 范数，又称为 **[欧几里得范数](https://www.bohrium.com/sciencepedia/feynman/keyword/2_norm) (Euclidean norm)** ，是我们从小到大最熟悉的距离概念。对于一个向量 $\vec{v}=(v_1, v_2, \dots, v_n)$ ，它的 $L_2$ 范数定义为： $\|\vec{v}\|_2 = \sqrt{v_1^2 + v_2^2 + \dots + v_n^2}$ 这正是毕达哥拉斯定理（勾股定理）在高维空间中的自然推广。它衡量的是空间中两点间的直线距离，“乌鸦飞行”的距离。这个范数与向量的 [点积](https://www.bohrium.com/sciencepedia/feynman/keyword/dot_product) （内积）有着密不可分的关系。一个向量的 $L_2$ 范数的平方，恰好等于它与自身的 [点积](https://www.bohrium.com/sciencepedia/feynman/keyword/dot_product) ： $\|\vec{v}\|_2^2 = \vec{v} \cdot \vec{v}$ 。

#### $L1$范数

想象一下你在一个像曼哈顿那样棋盘式规划的城市里，从一个街角走到另一个街角。你不能径直穿过建筑物，只能沿着街道行走。你走过的总距离，就是你在水平方向上走过的街区数，加上在垂直方向上走过的街区数。这就是 **$L_1$ 范数** ，又称 **[曼哈顿范数](https://www.bohrium.com/sciencepedia/feynman/keyword/manhattan_norm) (Manhattan norm)** 或 **[出租车范数](https://www.bohrium.com/sciencepedia/feynman/keyword/taxicab_norm) (taxicab norm)** 的核心思想。其定义为： $\|\vec{v}\|_1 = |v_1| + |v_2| + \dots + |v_n|$ 它测量的是沿着坐标轴方向移动的总距离。

#### $L\infty$范数
**$L_\infty$ 范数** ，也叫 **[无穷范数](https://www.bohrium.com/sciencepedia/feynman/keyword/infinity_norm_2) (infinity norm)** 或 **[最大范数](https://www.bohrium.com/sciencepedia/feynman/keyword/maximum_norm) (maximum norm)** 。它的思想极为简洁：一个 [向量的大小](https://www.bohrium.com/sciencepedia/feynman/keyword/magnitude_of_a_vector) ，由其所有分量中 [绝对值](https://www.bohrium.com/sciencepedia/feynman/keyword/absolute_value) 最大的那个来决定。 $\|\vec{v}\|_\infty = \max(|v_1|, |v_2|, \dots, |v_n|)$ 这种范数在处理“瓶颈”问题或评估“最坏情况”时特别有用。例如，一个机器人手臂有两个关节，如果它的质量标准是任何一个关节的偏差都不能超过某个阈值，那么我们关心的就是两个偏差值中较大的那个，这正是 $L_\infty$ 范数的应用场景。

为了更具体地感受它们的不同，让我们看一个向量 $\vec{v} = (1, 0, -2, 0, 4)$ 。

- 它的 $L_1$ 范数是： $\|\vec{v}\|_1 = |1| + |0| + |-2| + |0| + |4| = 7$ 。
- 它的 $L_2$ 范数是： $\|\vec{v}\|_2 = \sqrt{1^2 + 0^2 + (-2)^2 + 0^2 + 4^2} = \sqrt{1+4+16} = \sqrt{21} \approx 4.58$ 。
- 它的 $L_\infty$ 范数是： $\|\vec{v}\|_\infty = \max(|1|, |0|, |-2|, |0|, |4|) = 4$ 。

对于同一个向量，三种不同的“尺子”给出了三个不同的“长度”读数。这引出了一个关键点：不存在唯一“正确”的范数。选择哪一种范数，取决于我们关心的是什么。例如，在一个通信系统中，信号向量被放大，奇数分量放大 $\alpha$ 倍，偶数分量放大 $\beta$ 倍。我们会发现，使用 $L_1$ 范数和 $L_2$ 范数来衡量信号的“总能量”增益，其结果会依赖于 $\alpha$ 和 $\beta$ 的不同组合，这说明不同的范数对信号分量的不同变化有着不同的敏感度。

### “一”的形状：范数的可视化

不同范数最直观、最令人惊叹的区别，体现在它们各自的“单位球”上。所谓 **[单位球](https://www.bohrium.com/sciencepedia/feynman/keyword/unit_ball) (unit ball)** ，指的是空间中所有范数值等于1的向量的集合。让我们在二维平面上画出这三个范数的 [单位球](https://www.bohrium.com/sciencepedia/feynman/keyword/unit_ball) ，看看“长度为1”到底意味着什么。

- **$L_2$ 范数** ：所有满足 $\sqrt{x_1^2 + x_2^2} = 1$ 的点 $(x_1, x_2)$ 构成了一个我们再熟悉不过的 **圆形** 。这是我们心中最标准的“单位球”。
- **$L_\infty$ 范数** ：所有满足 $\max(|x_1|, |x_2|) = 1$ 的点构成了一个 **正方形** ，其顶点位于 $(1,1), (1,-1), (-1,1), (-1,-1)$ 。这是因为这个条件等价于 $-1 \le x_1 \le 1$ 和 $-1 \le x_2 \le 1$ 同时成立，且至少有一个分量的 [绝对值](https://www.bohrium.com/sciencepedia/feynman/keyword/absolute_value) 等于1。
- **$L_1$ 范数** ：所有满足 $|x_1| + |x_2| = 1$ 的点构成了一个旋转了45度的 **菱形（或钻石形）** ，其顶点位于 $(1,0), (0,1), (-1,0), (0,-1)$ 。

想象一下，一个机器人手臂的末端位置由向量 $\vec{x}=(x_1, x_2)$ 描述。如果质量控制协议A规定，只要 $\max(|x_1|, |x_2|) \le T$ 就合格，那么可接受的区域就是一个边长为 $2T$ 的正方形。而如果协议B规定 $|x_1| + |x_2| \le S$ 就合格，那么可接受的区域就是一个对角线长为 $2S$ 的菱形。你会发现，要让这个菱形区域恰好能容纳下那个正方形区域，菱形的面积必须是正方形面积的两倍。 这不仅仅是一个有趣的几何问题，它直观地展示了不同范数如何定义出形状和大小都截然不同的“安全区”。

### 大一统：$Lp$范数的连续统

这三种范数是孤立的概念，还是背后有着更深的联系？答案是后者。它们实际上都属于一个更宏大的 **$L_p$ 范数** 家族，其通用定义为： $\|x\|_p = \left( \sum_{i=1}^n |x_i|^p \right)^{1/p}$ 其中 $p \ge 1$ 。

当 $p=1$ 时，我们得到 $L_1$ 范数。当 $p=2$ 时，我们得到 $L_2$ 范数。那么，当 $p$ 变得非常非常大时会发生什么呢？

让我们来做一个思想实验。考虑向量 $e = (-3.5, 7.2, -1.0, 4.8)$ 。其中 [绝对值](https://www.bohrium.com/sciencepedia/feynman/keyword/absolute_value) 最大的分量是 $|7.2|=7.2$ 。当我们计算 $\|e\|_p$ 时，我们需要计算每个分量 [绝对值](https://www.bohrium.com/sciencepedia/feynman/keyword/absolute_value) 的 $p$ 次方。当 $p$ 很大时，比如 $p=100$ ，那么 $7.2^{100}$ 将会是一个天文数字，而像 $3.5^{100}$ 这样的其他项，虽然也很大，但与前者相比就变得微不足道了。整个求和 $\sum |e_i|^p$ 将几乎完全由 [最大项](https://www.bohrium.com/sciencepedia/feynman/keyword/maxterm) $(7.2)^p$ 所主导。

当我们再对这个和取 $1/p$ 次方根时，那些相对较小的项的影响就几乎被完全抹去了。在极限情况下，当 $p \to \infty$ 时，我们得到一个非常漂亮的结果： $\|x\|_\infty = \lim_{p \to \infty} \|x\|_p = \max_{i} |x_i|$ 也就是说， **$L_\infty$ 范数正是 $L_p$ 范数在 $p$ 趋向于无穷时的自然极限！**

这揭示了一个深刻的统一性： $L_1$ 、 $L_2$ 和 $L_\infty$ 范数并非各自为政，而是同一个 [连续谱](https://www.bohrium.com/sciencepedia/feynman/keyword/continuous_spectrum) 系上三个有代表性的点。它们共同描绘了从“加总所有”到“只看最大”的平滑过渡。这一发现如同一道光，照亮了整个 $L_p$ 范数家族的内在结构，展现了数学概念之间和谐统一的美感。

### 广义范数与对偶范数


在某些应用中，空间本身可能就不是“均匀”的。例如，在一个存在能量场的工作台面上，机器人手臂在不同方向上移动受到的“应力”可能不同。这种各向异性的空间可以用一个称为 **马氏范数 (Mahalanobis norm)** 或 **广义二次范数** 的概念来描述，其形式为 $S(x) = \sqrt{x^T A x}$ ，其中 $A$ 是一个 [对称正定矩阵](https://www.bohrium.com/sciencepedia/feynman/keyword/symmetric_positive_definite_matrix) 。当 $A$ 是单位矩阵时，它就退化为我们熟悉的 $L_2$ 范数。这种范数允许我们为空间定义一个“定制”的几何结构，就像在测量距离前先对空间进行拉伸和旋转。

此外，在数学的许多领域，重要的概念往往成对出现，范数也不例外。每个范数都有一个与之共生的“影子”—— **[对偶范数](https://www.bohrium.com/sciencepedia/feynman/keyword/dual_norms) (dual norm)** 。一个范数的 [对偶范数](https://www.bohrium.com/sciencepedia/feynman/keyword/dual_norms) ，可以被直观地理解为衡量“投影”或“相互作用强度”的极限。一个极其优美的例子是 $L_1$ 范数和 $L_\infty$ 范数之间的关系。可以证明，它们互为对偶。这意味着，对于任意一个向量 $x$ ，它与所有 $L_1$ 范数为1的向量 $y$ 的 [点积](https://www.bohrium.com/sciencepedia/feynman/keyword/dot_product) $|x \cdot y|$ ，其可能的最大值恰好就是 $x$ 的 $L_\infty$ 范数！
$\|x\|_\infty = \max_{\|y\|_1=1} |x \cdot y|$ 这个等式如同一座桥梁，将两种看似截然不同的度量方式令人惊奇地联系在一起。它告诉我们，一个向量在“最坏情况”下的分量大小（ $L_\infty$ ），可以通过它与所有“单位预算”的路径（ $L_1$ 单位球）相互作用的最大潜力来衡量。这正是数学深处隐藏的对称与和谐之美的又一例证。

## 应用与交叉学科联系

我们已经了解了 [向量范数](https://www.bohrium.com/sciencepedia/feynman/keyword/vector_norms) 是什么——它们是衡量向量“大小”或“长度”的数学工具。但正如物理学的魅力不仅在于公式本身，更在于它能解释从苹果下落到星系运行的万千现象一样， [向量范数](https://www.bohrium.com/sciencepedia/feynman/keyword/vector_norms) 的真正力量也体现在它广泛而深刻的应用之中。这些抽象的定义一旦与现实世界的问题相结合，便会绽放出令人惊叹的智慧之光。现在，让我们踏上一段旅程，看看 [向量范数](https://www.bohrium.com/sciencepedia/feynman/keyword/vector_norms) 是如何在城市规划、工程、 [数据科学](https://www.bohrium.com/sciencepedia/feynman/keyword/data_science) 乃至人工智能伦理等领域中大显身手的。

### 穿梭于世界：距离的几何学

想象一下，我们生活在一个完美的网格状城市中，就像曼哈顿或许多现代城市的棋盘式布局。一家物流公司需要将包裹从仓库送到客户手中。他们有两种交通工具：一种是能够“飞檐走壁”的无人机，它可以沿两点之间的直线飞行；另一种是只能沿着街道行驶的地面机器人。

- 无人机的路径是两点间的最短距离，这正是我们最熟悉的 **[欧几里得距离](https://www.bohrium.com/sciencepedia/feynman/keyword/euclidean_distance)** ，也就是向量的 $L_2$ 范数。如果你有一个从起点到终点的位移向量 $\mathbf{d} = (\Delta x, \Delta y)$ ，无人机飞行的距离就是 $\lVert\mathbf{d}\rVert_2 = \sqrt{(\Delta x)^2 + (\Delta y)^2}$ 。
- 地面机器人则必须沿着网格走，它走过的最短距离是横向移动的距离与纵向移动的距离之和。这恰好是位移向量的 **$L_1$ 范数** ，即 $\lVert\mathbf{d}\rVert_1 = |\Delta x| + |\Delta y|$ ，因此它也被亲切地称为“ [曼哈顿距离](https://www.bohrium.com/sciencepedia/feynman/keyword/manhattan_distance) ”或“出租车几何距离”。

这个简单的例子生动地揭示了不同 [范数的几何](https://www.bohrium.com/sciencepedia/feynman/keyword/geometry_of_norms) 本质：它们代表了在不同“运动规则”下对距离的定义。 $L_2$ 范数是我们在开放空间中体验到的距离，而 $L_1$ 范数则是在受约束的网格世界中的自然选择。

这种思想可以进一步推广。想象一下在棋盘上移动的国王。国王每一步可以横走、竖走或斜走一格。从一个格子到另一个格子的最少步数是多少呢？假设位移向量是 $\mathbf{d} = (\Delta x, \Delta y)$ 。为了走完 $\Delta x$ 的水平距离和 $\Delta y$ 的 [垂直距离](https://www.bohrium.com/sciencepedia/feynman/keyword/perpendicular_distance) ，国王在每一步中最多能将水平和 [垂直距离](https://www.bohrium.com/sciencepedia/feynman/keyword/perpendicular_distance) 各缩短1。因此，总步数至少是 $\Delta x$ 和 $\Delta y$ 中较大的那个。事实上，通过组合使用斜向和直线移动，这个步数也总是可以达到的。这正是 **$L_\infty$ 范数** （或称 [切比雪夫距离](https://www.bohrium.com/sciencepedia/feynman/keyword/chebyshev_distance) ）的定义： $K = \max(|\Delta x|, |\Delta y|) = \lVert\mathbf{d}\rVert_\infty$ 。

从无人机、地面机器人到棋盘上的国王，我们看到，选择哪种范数来衡量距离，取决于我们所处空间的“游戏规则”。

### 工程、机器人学与安全：量化与控制误差

在工程和科学领域，我们永远在与误差作斗争。测量有误差，机器人定位有误差，模型预测也有误差。 [向量范数](https://www.bohrium.com/sciencepedia/feynman/keyword/vector_norms) 为我们提供了一套强大的语言来量化和评估这些误差。

假设一个机器臂的目标位置是 $\mathbf{p}_{\text{true}}$ ，但它实际到达的位置是 $\mathbf{p}_{\text{est}}$ 。误差向量就是 $\mathbf{e} = \mathbf{p}_{\text{est}} - \mathbf{p}_{\text{true}}$ 。这个误差向量“有多大”？答案取决于你关心的是什么。

- **最坏情况下的误差** ：在许多高精度应用中，比如桥梁的结构安全分析或精密制造，我们最关心的是 **任何一个方向上** 的最大误差是否超出了安全阈值。例如，工程师需要确保桥梁上没有任何一个节点的位移超过临界值 $D_{\max}$ 。或者，在机器人定位中，我们需要保证沿 x、y、z 任何一个轴的偏差都不会导致灾难性的失败。在这种情况下，最合适的度量工具就是 **$L_\infty$ 范数** ， $\lVert\mathbf{e}\rVert_\infty = \max_i |e_i|$ 。它直接告诉我们误差向量中最大的分量，完美地捕捉了“最薄弱环节”的思想。
- **总误差的累积** ：在另一些场景中，我们可能更关心误差的总体累积效应。例如，一个机器臂的每个关节都由独立的电机驱动。要修正位置误差 $\mathbf{e} = (e_x, e_y, e_z)$ ，每个轴向的电机需要付出的能量（或工作量）可能与各自的误差 [绝对值](https://www.bohrium.com/sciencepedia/feynman/keyword/absolute_value) 成正比。那么，修正整个误差所需的总能量就与各个轴向误差 [绝对值](https://www.bohrium.com/sciencepedia/feynman/keyword/absolute_value) 之和成正比，即 $|e_x| + |e_y| + |e_z|$ 。这正是 **$L_1$ 范数** $\lVert\mathbf{e}\rVert_1$ 。
- **能量或信号强度** ： $L_2$ 范数的平方， $\lVert\mathbf{e}\rVert_2^2 = \sum_i e_i^2$ ，在物理学中与能量、功率或强度等概念密切相关。它衡量的是误差的“均方根”大小，对较大的误差给予比 $L_1$ 范数更大的“惩罚”。

因此，对于同一个误差向量，不同的范数就像从不同角度拍摄的照片，每一张都揭示了误差的一种重要特性。工程师会根据具体的目标——是控制峰值风险，还是最小化总成本——来选择最合适的范数。

### 数据、信号与推断的艺术：从最小二乘到稀疏革命

现代 [数据科学](https://www.bohrium.com/sciencepedia/feynman/keyword/data_science) 、统计学和机器学习
#### $L2$范数与最小二乘法

你可能听说过“线性回归”或“ [最小二乘法](https://www.bohrium.com/sciencepedia/feynman/keyword/method_of_least_squares) ”，这是数据分析的入门必备。当你试图用一条直线 $y = mx+c$ 拟合一堆数据点 $(x_i, y_i)$ 时，你通常会调整 $m$ 和 $c$ ，使得所有数据点的“ [残差](https://www.bohrium.com/sciencepedia/feynman/keyword/residue) ”（真实值 $y_i$ 与模型预测值 $\hat{y}_i$ 的差）的平方和最小。这个 [残差平方和](https://www.bohrium.com/sciencepedia/feynman/keyword/residual_sum_of_squares) ， 
$\sum_i (y_i - \hat{y}_i)^2$ ，其实就是 [残差向量](https://www.bohrium.com/sciencepedia/feynman/keyword/residual_vector) $\mathbf{r}$ 的 $L_2$ 范数的平方， $\lVert\mathbf{r}\rVert_2^2$ 。

这背后有一个优美的几何图像。所有可能的预测向量 $\hat{\mathbf{y}}$ 构成了由数据矩阵的列所张成的一个子空间（称为列空间）。最小二乘法的解，就是在这个子空间中寻找一个离真实观测向量 $\mathbf{y}$ **最近** 的点。这里的“最近”，正是在欧几里得意义下，即最小化 $L_2$ 距离。这个解就是 $\mathbf{y}$ 在该子空间上的 **正交投影** ，而 [残差向量](https://www.bohrium.com/sciencepedia/feynman/keyword/residual_vector) $\mathbf{r} = \mathbf{y} - \hat{\mathbf{y}}$ 则与整个子空间垂直。这种基于 $L_2$ 范数的优化方法，因其良好的数学性质和物理直觉（如最小化能量），在科学和工程中占据了数百年的主导地位。

####$L1$ 范数、稀疏性与稳健性

尽管 $L_2$ 范数非常成功，但它并非万能。它有一个著名的弱点：对“离群点”（outliers）异常敏感。想象一下，在拟合直线时，大部分点都 [排列](https://www.bohrium.com/sciencepedia/feynman/keyword/permutation) 整齐，只有一个点离得很远。为了最小化平方和， $L_2$ 方法会极力“讨好”这个离群点，导致拟合的直线偏离大多数数据的真实趋势。

相比之下，如果我们最小化的是 [残差](https://www.bohrium.com/sciencepedia/feynman/keyword/residue) 的 **$L_1$ 范数** ，即 $\sum_i |y_i - \hat{y}_i|$ （称为 [最小绝对偏差](https://www.bohrium.com/sciencepedia/feynman/keyword/least_absolute_deviations) ，LAD），情况就大为不同。由于 $L_1$ 范数对误差的惩罚是线性的，它不会像 $L_2$ 那样对大的误差给予不成比例的权重。因此，LAD方法对离群点有更强的“抵抗力”，能给出更稳健的拟合结果。从统计学的角度看， [最小二乘法](https://www.bohrium.com/sciencepedia/feynman/keyword/method_of_least_squares) （ $L_2$ ）最终找到了数据的 **均值** ，而 [最小绝对偏差](https://www.bohrium.com/sciencepedia/feynman/keyword/least_absolute_deviations) （ $L_1$ ）则找到了数据的 **中位数** 。我们知道， [中位数](https://www.bohrium.com/sciencepedia/feynman/keyword/median) 对极端值不敏感，而均值则不然。这种稳健性使得 $L_1$ 范数在处理含有噪声或异常值的真实世界数据时极具价值。

$L_1$ 范数更引人注目的“魔力”在于它能够发现 **稀疏（sparse）** 解。在许多问题中，比如信号处理和机器学习，我们相信底层的重要因素是少数几个。例如，一张图片可能可以用少数几个关键的边缘和纹理来表示；一种疾病的 [遗传标记](https://www.bohrium.com/sciencepedia/feynman/keyword/genetic_markers) 可能只涉及少数几个基因。

考虑一个“欠定”系统 $A\mathbf{x}=\mathbf{b}$ ，即未知量（ $\mathbf{x}$ 的维度）多于方程（ $\mathbf{b}$ 的维度）。这样的系统有无穷多组解。我们应该选择哪一个呢？

- 如果我们寻找满足约束且 **$L_2$ 范数最小** 的解，我们通常会得到一个“稠密”的解，其中每个分量都不为零，能量均匀地分布在所有分量上。
- 而如果我们寻找 **$L_1$ 范数最小** 的解，奇迹发生了：我们倾向于得到一个“稀疏”解，其中大部分分量都恰好为零！

这一现象是“ [压缩感知](https://www.bohrium.com/sciencepedia/feynman/keyword/compressive_sensing) ”领域的基石，它彻底改变了信号采集的方式，尤其是在医学成像（如MRI）等领域，可以在采集更少数据的情况下重建出高质量的图像。

这种稀疏诱导的特性在机器学习的“ [特征选择](https://www.bohrium.com/sciencepedia/feynman/keyword/feature_selection) ”中也至关重要。在构建 [预测模型](https://www.bohrium.com/sciencepedia/feynman/keyword/forecasting_models) 时，我们常常面临成千上万个潜在的输入特征，但可能只有少数是真正有用的。通过在损失函数中加入模型权重向量 $\mathbf{w}$ 的 $L_1$ 范数作为“正则化项”（这被称为 [Lasso回归](https://www.bohrium.com/sciencepedia/feynman/keyword/lasso_regression) ），我们可以“鼓励”模型将许多不重要特征的权重自动设置为零。

为什么 $L_1$ 范数有这种魔力，而 $L_2$ 范数没有？几何学给了我们一个直观的答案。在二维空间中，所有 $L_1$ 范数等于常数的点构成一个菱形（一个在坐标轴上拥有“尖角”的正方形），而所有 $L_2$ 范数等于常数的点构成一个圆形。当模型的损失函数的等高线（椭圆）从中心扩展，与这些形状首次接触时：

- 与光滑的圆形（ $L_2$ 约束）接触的点，几乎总是在一个两个坐标都不为零的地方。
- 而与带有尖角的菱形（ $L_1$ 约束）接触的点，则有很大概率发生在坐标轴上的某个“尖角”处，这会迫使其中一个坐标恰好为零。 这种几何上的差异，正是 $L_1$ 带来 [稀疏性](https://www.bohrium.com/sciencepedia/feynman/keyword/sparsity) 而 $L_2$ 带来平滑缩减的根源。

经济学与公平性中的规范

- **[资源分配](https://www.bohrium.com/sciencepedia/feynman/keyword/resource_allocation) 与政策制定** ：在一个 [资源分配模型](https://www.bohrium.com/sciencepedia/feynman/keyword/resource_allocation_model) 中，向量 $\mathbf{x}$ 代表分配给各个项目的资源。我们可以用范数来施加政策约束。例如， $\lVert\mathbf{x}\rVert_1 \le T$ 可以代表总预算有限，所有项目的资源总和不能超过 $T$ 。而 $\lVert\mathbf{x}\rVert_\infty \le U$ 则可以代表公平性原则或风险控制，确保没有任何一个项目获得过多的资源。选择不同的范数作为约束，就等于选择了不同的政策导向。
- **[环境经济学](https://www.bohrium.com/sciencepedia/feynman/keyword/environmental_economics)** ：假设一个监管机构要对企业的污染排放征税。污染源可以表示为一个向量 $\mathbf{p}$ ，其中 $p_i$ 是第 $i$ 个污染源的排放量。
	- 如果税收基于 $L_1$ 范数，即 $T_1 = \tau \lVert\mathbf{p}\rVert_1 = \tau \sum p_i$ ，这相当于对总排放量征收的统一碳税。它只关心总量，不关心排放的分布。
		- 如果税收基于 $L_2$ 范数，即 $T_2 = \tau \lVert\mathbf{p}\rVert_2 = \tau \sqrt{\sum p_i^2}$ ，情况就不同了。由于平方项的存在， $L_2$ 范数对大的排放源惩罚更重。在总排放量相同的情况下，将污染集中在一个源头会比 [均匀分布](https://www.bohrium.com/sciencepedia/feynman/keyword/uniform_distribution) 在多个源头产生更高的税收。因此，基于 $L_2$ 范数的税收政策会激励企业在各个污染源之间更均衡地减排。在此，范数的选择直接体现了不同的环境治理哲学。
- **人工智能的公平性** ：当我们部署一个机器学习模型（如用于贷款审批或疾病诊断）时，我们必须确保它对不同的人群（如不同种族、性别）是公平的。我们可以用一个误差向量 $\mathbf{e}$ 来表示模型在各个群体上的错误率。一个理想的模型应该对所有群体一视同仁，即所有 $e_i$ 都应该大致相等。我们可以定义一个“不公平性”向量 $\mathbf{d}$ ，其分量 $d_i = e_i - \bar{e}$ 是每个群体的错误率与平均错误率的偏差。那么， **$\lVert\mathbf{d}\rVert_\infty = \max_i |d_i|$** 就成了一个衡量“最坏情况不公平性”的绝佳指标。通过努力最小化这个 $L_\infty$ 范数，我们致力于确保没有任何一个群体受到比其他群体严重得多的伤害，这为量化和改进 [算法公平性](https://www.bohrium.com/sciencepedia/feynman/keyword/algorithmic_fairness) 提供了一条清晰的路径。

### 范数的对偶与对抗世界

最后，让我们一窥 [向量范数](https://www.bohrium.com/sciencepedia/feynman/keyword/vector_norms) 在 [人工智能安全](https://www.bohrium.com/sciencepedia/feynman/keyword/ai_security) 这一前沿领域的迷人应用。现代机器学习模型，尤其是 [深度神经网络](https://www.bohrium.com/sciencepedia/feynman/keyword/deep_neural_networks) ，被发现容易受到“ [对抗性攻击](https://www.bohrium.com/sciencepedia/feynman/keyword/adversarial_attacks) ”。攻击者只需对输入（如一张图片）施加一个极其微小、人眼难以察觉的扰动 $\delta\mathbf{x}$ ，就能让模型做出完全错误的判断（例如，将熊猫识别为长臂猿）。

为了构建更稳健的模型，我们需要理解模型在何种情况下最脆弱。假设攻击者被限制在一个“扰动预算”内，即扰动的大小 $\lVert\delta\mathbf{x}\rVert_p \le \epsilon$ ，其中 $p$ 可以是 $1, 2, \infty$ 等。攻击者的目标是找到一个满足该约束的 $\delta\mathbf{x}$ ，使得模型的损失增加得最多。

这里出现了一个深刻的数学结论：对于一个 [线性分类器](https://www.bohrium.com/sciencepedia/feynman/keyword/linear_classifier) ，其权重为 $\mathbf{w}$ ，在输入扰动受 $L_p$ 范数约束时，它所面临的最坏情况下的损失增加量，正比于其权重向量的 **$L_q$ 范数** ，其中 $1/p + 1/q = 1$ 。 $L_p$ 和 $L_q$ 范数构成了一对“ [对偶范数](https://www.bohrium.com/sciencepedia/feynman/keyword/dual_norms) ”。

这意味着：

- 如果攻击者可以在每个像素上做微小改动（ $L_\infty$ 攻击），模型的脆弱性取决于其权重的 $L_1$ 范数。
- 如果攻击者的总扰动能量有限（ $L_2$ 攻击），模型的脆弱性则取决于其权重的 $L_2$ 范数。

这个对偶关系 不仅美妙，而且极其有用。它揭示了输入空间和权重空间之间的深刻联系，指导我们通过对模型权重施加特定范数的正则化，来防御相应类型的攻击，从而构建更安全、更可靠的人工智能系统。
