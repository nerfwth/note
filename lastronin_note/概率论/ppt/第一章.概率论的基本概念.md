# 随机试验
- 相同条件下可重复进行
	*可重复*
- 每次试验的可能结果不止一个，且所有结果事前已知   
    *预知全部可能结果*
- 试验前不知道会发生何种情况
	*随机性*



# 样本空间
![[Pasted image 20261025153725.png]]
- 随机试验所有可能结果的集合

 ## 样本点
 随机试验中一个**不可再分**的可能结果
 从而样本空间就是样本点的集合。
 
 ## 离散样本空间
 - 样本点为有限个或可列个
 ## 连续样本空间
 - 样本点为不可列无限个
 ## 事件发生
 - 在每次试验中，事件有且仅有一个样本点出现。
 ![[Pasted image 20261025153122.png]]
 
 

# 随机事件
![[Pasted image 20261025153027.png]]
- 样本空间的子集为随机试验的随机事件。
- 由一个样本点组成的单点集称为**基本事件**
- 必然事件
- 不可能事件
