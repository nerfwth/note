# 随机试验
- 相同条件下可重复进行
- 每次试验的可能结果不止一个，且所有结果事前已知   
    *随机！=不确定*
- 试验前不知道会发生何种情况
	*随机性*



# 样本空间

- 随机试验所有可能结果的集合

 样本点：随机试验中一个**不可再分**的可能结果
 从而样本空间就是样本点的集合

# 随机事件
- 样本空间的子集为随机试验的随机事件。
- 由一个样本点组成的单点集称为**基本事件**
